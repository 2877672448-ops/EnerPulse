# EnerPulse 数据库设计（可开发版）

> 版本：v1.0.0  
> 用途：数据库建模、建表、ORM、数据迁移、查询开发的统一依据。  
> 数据库实现选型尚未由原始说明书规定；以下 SQL 以 **PostgreSQL 15+** 为示例技术基线。若项目最终选择其他数据库，仅转换语法，不改变业务模型。

---

# 1. 业务数据模型

```text
tenant
 ├── user ── role ── permission
 ├── area
 │    └── device
 │         └── point
 ├── gateway
 │    └── point
 ├── dictionary
 ├── tariff_period ── tariff
 ├── energy_raw_data
 ├── energy_hourly
 ├── energy_daily
 ├── energy_monthly
```

```sql
timestamptz
```

# 3. DDL

## 3.1 tenant

```sql
create table tenants (
    id bigint generated by default as identity primary key,
    name varchar(128) not null,
    code varchar(64) not null unique,
    status varchar(32) not null default 'ACTIVE',
    created_at timestamptz not null default now(),
    updated_at timestamptz not null default now()
);
```

---

## 3.2 users

```sql
create table users (
    id bigint generated by default as identity primary key,
    tenant_id bigint not null references tenants(id),
    username varchar(64) not null,
    password_hash varchar(255) not null,
    nickname varchar(128),
    mobile varchar(32),
    email varchar(128),
    status varchar(32) not null default 'ACTIVE',
    last_login_at timestamptz,
    created_at timestamptz not null default now(),
    updated_at timestamptz not null default now(),
    deleted_at timestamptz,
    unique (tenant_id, username)
);
```

原系统支持用户新增、修改、删除、重置密码。fileciteturn0file0L151-L175

## 3.3 roles / permissions

```sql
create table roles (
    id bigint generated by default as identity primary key,
    tenant_id bigint not null references tenants(id),
    name varchar(64) not null,
    code varchar(64) not null,
    description varchar(255),
    status varchar(32) not null default 'ACTIVE',
    unique (tenant_id, code)
);

create table permissions (
    id bigint generated by default as identity primary key,
    code varchar(128) not null unique,
    name varchar(128) not null,
    type varchar(32) not null,
    resource varchar(255),
    action varchar(64),
    description varchar(255)
);

create table user_roles (
    user_id bigint not null references users(id),
    role_id bigint not null references roles(id),
    primary key (user_id, role_id)
);

create table role_permissions (
    role_id bigint not null references roles(id),
    permission_id bigint not null references permissions(id),
    primary key (role_id, permission_id)
);
```

角色权限配置属于原系统能力范围。fileciteturn0file0L195-L223

# 9. 峰平谷与费率

```sql
create table tariff_periods (
    id bigint generated by default as identity primary key,
    tenant_id bigint not null references tenants(id),
    name varchar(64) not null,
    period_type varchar(16) not null,
    start_time time not null,
    end_time time not null,

    status varchar(32) not null default 'ACTIVE'

create table tariffs (
    id bigint generated by default as identity primary key,
```

# 10. 原始能源数据

```sql
create table energy_raw_data (
    id bigint generated by default as identity primary key,
    tenant_id bigint not null,
    gateway_id bigint not null,
    device_id bigint,
    point_id bigint not null,
    ts timestamptz not null,
    value numeric(30,10) not null,
    quality varchar(32) not null default 'GOOD',
    unit varchar(32),
    message_id varchar(128),
    raw_payload jsonb,
    received_at timestamptz not null default now()
);

create index idx_energy_raw_point_ts
    on energy_raw_data(point_id, ts desc);

create index idx_energy_raw_device_ts
    on energy_raw_data(device_id, ts desc);

create index idx_energy_raw_gateway_ts
    on energy_raw_data(gateway_id, ts desc);

create unique index uk_energy_raw_message_point
    on energy_raw_data(message_id, point_id)
    where message_id is not null;
```

# 13. 告警与通知

```sql
create table alarms (
    id bigint generated by default as identity primary key,
    tenant_id bigint not null,
    gateway_id bigint,
    device_id bigint,
    point_id bigint,
    alarm_code varchar(64) not null,
    alarm_type varchar(64),
    level varchar(16) not null,
    message varchar(500),
    value numeric(30,10),
    threshold numeric(30,10),
    status varchar(32) not null default 'ACTIVE',
    occurred_at timestamptz not null,
    recovered_at timestamptz,
    ack_by bigint references users(id),
    ack_at timestamptz,
    closed_by bigint references users(id),
    closed_at timestamptz,
    created_at timestamptz not null default now()
);

create index idx_alarms_tenant_occurred
    on alarms(tenant_id, occurred_at desc);

create table notifications (
    id bigint generated by default as identity primary key,
    tenant_id bigint not null,
    alarm_id bigint not null references alarms(id),
    channel varchar(32) not null,
    recipient varchar(255) not null,
    status varchar(32) not null default 'PENDING',
    sent_at timestamptz,
    error_message varchar(1000),
    created_at timestamptz not null default now()
);
```

原系统支持 MQTT 告警记录、历史告警和微信远程告警。fileciteturn0file0L476-L531

# 16. 索引原则

必须具备：

```text
点位 + 时间
设备 + 时间
网关 + 时间
租户 + 时间
告警 + 时间
日志 + 时间
```

查询能源数据时，必须优先走时间范围条件。
